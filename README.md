# 鳥取市議選2026 かんたんガイド

令和8年（2026年）11月22日（日）投票の鳥取市議会議員選挙を、有権者向けに分かりやすくまとめた非公式ページです。

- 選挙のきほん（定数32・立候補43人）
- 当日の投票のしかた・期日前投票所の一覧
- 候補者43人の見出しと公約（選挙公報の原文のまま、テーマ・党派・言葉でしぼりこみ可能）

## 出典

- [鳥取市議会議員選挙のお知らせ（鳥取市選挙管理委員会）](https://www.city.tottori.lg.jp/page/42131.html)
- [立候補届出者一覧（PDF）](https://www.city.tottori.lg.jp/uploaded/attachment/54798.pdf)
- [選挙公報（PDF）](https://www.city.tottori.lg.jp/uploaded/attachment/54816.pdf)

## ファイル

| パス | 内容 |
|---|---|
| `index.html` | ページ本体（1ファイル。`data/candidates.json` を読み込む） |
| `data/official.json` | 選管の候補者一覧（名前・党派・ウェブサイト） |
| `data/candidates.json` | 公報の文字起こしと選管一覧を合わせたもの（ページが使うデータ） |
| `tools/merge.py` | 上の2つを作るスクリプト |

## 方針

- 特定の候補者・政党を応援・批判しない。並び順は選挙公報の掲載順。
- 候補者の文章は要約せず原文どおり。党派は選管の届出どおり。
- 人気投票・当落予想は載せない（公職選挙法で人気投票の公表は禁止）。

## ローカルで見る

```bash
python3 -m http.server 8931
```

http://127.0.0.1:8931/ を開く。
